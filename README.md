# 🎓 Student Management System

A modern, responsive, and fully functional **Student Management System** built with **React**, **Redux Toolkit**, and **Tailwind CSS**. This application allows users to perform full CRUD (Create, Read, Update, Delete) operations on student records seamlessly.

---

## ✨ Features

* ➕ **Add New Students**: Easily add student details including Name, Email, and Course.
* 📝 **Edit Student Details**: Update existing student records with smooth form pre-filling.
* 🗑️ **Delete Student Records**: Remove students instantly from the global Redux state.
* ⚡ **State Management**: Built using **Redux Toolkit** for clean, predictable central state handling.
* 📱 **Responsive UI**: Clean and mobile-friendly user interface styled with **Tailwind CSS**.
* 🛡️ **Validation**: Basic form inputs required check before dispatching actions.

---

## 🛠️ Tech Stack

* **Frontend**: React.js (Vite)
* **State Management**: Redux Toolkit (`@reduxjs/toolkit` & `react-redux`)
* **Styling**: Tailwind CSS
* **Icons & UI**: Tailwind Utility Classes

## 🚀 Getting Started

Follow these steps to get a copy of the project up and running on your local machine for development and testing purposes:

### 📋 Prerequisites
Ensure you have the following installed on your system:
* [Node.js](https://nodejs.org/) (v16.0.0 or higher)
* [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
* [Git](https://git-scm.com/)

---

## 🔧 Installation & Setup

1. **Clone the repository:**
   ```
   git clone [https://github.com/RaganiKumari9798/Student-Management-System.git](https://github.com/RaganiKumari9798/Student-Management-System.git)
   
   ```

### 2. Navigate into the project directory:
cd Student-Management-System

### 3.  Install project dependencies:
npm install

### 4. Start the local development server:
npm run dev

### 5. Open in Browser:
Open your browser and navigate to http://localhost:5173/ (or the URL shown in your terminal).
